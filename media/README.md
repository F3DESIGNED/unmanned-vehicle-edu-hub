# Media

Organized media files for documentation.

## Structure

- **images/diagrams/**: Technical diagrams and schematics
- **images/components/**: Component photos with labels
- **images/builds/**: Build process and completed projects
- **attribution.md**: Attribution for all images used

## Adding Media

When adding images:
1. Use descriptive filenames (e.g., `fc-wiring-diagram.png`)
2. Place in appropriate subfolder
3. Update attribution.md with source/license
4. Optimize for web (compress images)
5. Include alt text in documentation
