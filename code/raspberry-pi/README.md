# Raspberry Pi Code

Python scripts and configurations for Raspberry Pi in unmanned vehicle systems.

## Purpose

Python code for MAVLink communication, computer vision, telemetry, GPIO control, and companion computer applications.

## Contents

- **basics/** - GPIO, sensors, displays
- **mavlink/** - Dronekit and pymavlink examples
- **computer-vision/** - OpenCV applications
- **telemetry/** - Data logging and transmission
- **ground-station/** - Custom GCS applications

## Requirements

- Raspberry Pi (3B+, 4, or 5 recommended)
- Python 3.7+
- Required packages (specified per script)
