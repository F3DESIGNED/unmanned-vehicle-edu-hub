# Arduino Code

Arduino sketches and libraries for unmanned vehicle systems.

## Purpose

Beginner-friendly to advanced Arduino code for sensors, motor control, communication, and complete vehicle projects.

## Contents

- **basics/** - LED, sensors, basic I/O
- **sensors/** - GPS, IMU, ultrasonic, etc.
- **motors/** - ESC control, servo control
- **communication/** - Serial, I2C, SPI
- **rovers/** - Complete ground vehicle projects
- **libraries/** - Custom libraries

## Requirements

- Arduino IDE 2.0+ or PlatformIO
- Compatible Arduino board (Uno, Mega, ESP32)
- Required libraries (specified per sketch)
