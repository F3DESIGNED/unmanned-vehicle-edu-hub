# Code Repository

Welcome to the code repository for the Unmanned Vehicle Systems Education Hub!

## Purpose

This directory contains working code examples, libraries, and scripts for Arduino, Raspberry Pi, flight controllers, ground stations, and utilities. All code is documented and tested for educational use.

## Directory Structure

```
code/
├── README.md (this file)
├── arduino/                  # Arduino sketches and libraries
├── raspberry-pi/             # Python scripts and Linux configs
├── flight-controllers/       # Custom firmware and scripts
├── ground-station/           # GCS tools and automation
└── utilities/                # Helper scripts and tools
```

## What You'll Find

### Arduino
- Sensor reading examples
- Motor control sketches

- Communication protocols
- Complete rover projects

### Raspberry Pi
- MAVLink/Dronekit scripts

- GPIO control examples
- Telemetry logging
- Ground station applications

### Flight Controllers
- Custom parameter files
- Lua scripts for ArduPilot
- Configuration templates
- Firmware build scripts

### Ground Station
- Mission planning tools
- Log analysis scripts
- Telemetry visualization
- Automation scripts

### Utilities
- Setup scripts
- Testing tools
- Calibration helpers
- Data converters

## Code Standards

All code follows our standards:
- **Python** - PEP 8 style
- **Arduino** - Arduino style guide
- **Comments** - Extensive for learning
- **Testing** - Verified working
- **Documentation** - Usage instructions included
