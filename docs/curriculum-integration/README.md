## Lesson Plan Structure

Each lesson plan includes:

1. **Overview** - Summary and objectives
2. **Standards Alignment** - Specific standards addressed
3. **Materials Required** - Equipment and supplies
4. **Safety Considerations** - Protocols and risks
5. **Preparation** - Teacher setup steps
6. **Instructional Sequence** - Step-by-step procedure
7. **Assessment** - How to evaluate learning
8. **Extensions** - Advanced challenges
9. **Accommodations** - Supporting diverse learners
10. **Resources** - Supporting materials

## Grade Level Pathways

### Elementary (K-5)

**Focus:** Concepts, observation, supervised activities
**Topics:**
- What are drones and robots?
- How do things fly/move?
- Basic remote control
- Safety awareness

**Time:** 30-45 minute lessons

### Middle School (6-8)

**Focus:** Building, block programming, experimentation
**Topics:**
- Building simple UAV/UGV
- Block-based programming (Scratch, Blockly)
- Sensors and data collection
- Flight/driving training

**Time:** 45-90 minute lessons or project days

### High School (9-12)

**Focus:** Advanced builds, text programming, research
**Topics:**
- Custom system design
- Python/C++ programming
- Autonomous missions
- Competition preparation
- Research projects

**Time:** Full project-based units (2-6 weeks)

## Sample Unit Progression

### Beginner Unit: "Introduction to Quadcopters" (6 lessons)

1. **Lesson 1** - What is a quadcopter? (concepts)
2. **Lesson 2** - Forces of flight (physics)
3. **Lesson 3** - Build a simple quadcopter (hands-on)
4. **Lesson 4** - Flight training basics (practice)
5. **Lesson 5** - Sensors and data (STEM integration)
6. **Lesson 6** - Final challenge (assessment)
