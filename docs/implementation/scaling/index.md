# Program Scaling Framework

Systematic approach to growing drone education programs from pilot to district-wide implementation.

## Scaling Pathways

### [Phase 1: Pilot Club](./growth-pathways/phase-1-pilot-club.md)
10-15 students, after-school, single teacher
→ Prove concept, build support

### [Phase 2: Single Class](./growth-pathways/phase-2-single-class.md)
20-30 students, credit course, established teacher
→ Demonstrate academic rigor, refine curriculum

### [Phase 3: Multiple Sections](./growth-pathways/phase-3-multiple-sections.md)
50-100 students, multiple sections, additional teachers
→ Build capacity, systematize operations

### [Phase 4: District Expansion](./growth-pathways/phase-4-district-expansion.md)
100+ students, multiple schools, program coordinator
→ Share resources, align curriculum

### [Phase 5: Regional Collaboration](./growth-pathways/phase-5-regional-collaboration.md)
500+ students, multi-district, shared resources
→ Economies of scale, advanced opportunities

## Key Considerations

### [Capacity Building](./capacity-building/)
Training additional teachers, developing student leadership

### [Resource Expansion](./resource-expansion/)
Scaling equipment, facilities, and support systems

### [Sustainability](./sustainability/)
Ensuring long-term viability as program grows
