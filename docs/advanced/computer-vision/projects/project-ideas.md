# Computer Vision Project Ideas

This document contains project ideas at various difficulty levels for students who have completed computer vision lessons. Each idea includes a brief description, difficulty level, and key skills practiced.

## Beginner Projects (2-3 weeks)

### 1. Color-Based Landing Pad Detector
**Description**: Detect a brightly colored landing pad and guide the drone to land on it autonomously.

**Key Skills**: Color space conversion, thresholding, centroid calculation, visual servoing

**Extensions**: Handle multiple colors, work in varying lighting, estimate distance

---

### 2. Line Following Drone
**Description**: Follow a colored line on the ground like a line-following robot, but from the air.

**Key Skills**: Edge detection, Hough transform, PID control, image processing

**Extensions**: Handle intersections, follow complex paths, adaptive speed

---

### 3. QR Code Scanner
**Description**: Autonomously search for and scan QR codes, decode information, and take action.

**Key Skills**: QR detection, decoding, search patterns, autonomous navigation

**Extensions**: Multiple codes, encrypted data, navigation based on decoded instructions

---

## Intermediate Projects (3-5 weeks)

### 4. Autonomous Object Search & Inventory
**Description**: Search a defined area, detect and count specific objects (toys, cones, etc.), create inventory report.

**Key Skills**: Object detection, GPS mapping, systematic search, data logging

**Extensions**: Multi-class detection, 3D mapping, change detection over time

---

### 5. Target Tracking & Following
**Description**: Detect a moving target (person, vehicle, ball) and autonomously follow while maintaining safe distance.

**Key Skills**: Object tracking, optical flow, distance estimation, safety boundaries

**Extensions**: Predict motion, handle occlusion, multiple target selection

---

### 6. Precision Agriculture Scout
**Description**: Fly over crops, detect problem areas (weeds, disease, dry patches), generate map report.

**Key Skills**: Image analysis, vegetation indices, anomaly detection, georeferencing

**Extensions**: Multispectral imaging, ML classification, action recommendations

---

### 7. Gesture Control System
**Description**: Control drone using hand gestures detected by onboard camera.

**Key Skills**: Hand detection, gesture recognition, real-time processing, safe control

**Extensions**: Custom gesture vocabulary, voice + gesture, adaptive learning

---

## Advanced Projects (5-8 weeks)

### 8. Visual SLAM for Indoor Navigation
**Description**: Navigate indoor environment without GPS using visual landmarks and SLAM algorithms.

**Key Skills**: Feature detection, camera calibration, pose estimation, mapping

**Extensions**: Loop closure, dense mapping, multi-floor navigation

---

### 9. Search & Rescue Object Detection
**Description**: Detect simulated distress signals (colored panels, shapes, or trained ML objects) in complex environment.

**Key Skills**: Object detection, search patterns, noise filtering, reliable reporting

**Extensions**: Thermal imaging simulation, multi-drone coordination, priority mapping

---

### 10. Autonomous Obstacle Course
**Description**: Navigate through obstacle course using only vision (gates, hoops, landing zones).

**Key Skills**: ArUco markers, pose estimation, path planning, precision flight

**Extensions**: Dynamic obstacles, time optimization, backup strategies

---

### 11. Custom Object Detector
**Description**: Collect training data, train custom ML model, deploy to detect specific objects in your environment.

**Key Skills**: Data collection, annotation, transfer learning, model deployment

**Extensions**: Multiple classes, data augmentation, model optimization

---

### 12. Traffic Monitoring System
**Description**: Monitor toy car "traffic", count vehicles, detect stopped cars, measure speeds.

**Key Skills**: Vehicle detection, tracking, speed calculation, analytics

**Extensions**: License plate reading (toy), traffic flow analysis, incident detection

---

## Expert Projects (8-12 weeks)

### 13. 3D Reconstruction from Aerial Photos
**Description**: Capture images from multiple angles, create 3D model of object or area.

**Key Skills**: Photogrammetry, structure from motion, point clouds, 3D visualization

**Extensions**: Texture mapping, mesh generation, volumetric measurements

---

### 14. Multi-Drone Coordinated Vision
**Description**: Multiple drones share visual information to accomplish tasks cooperatively.

**Key Skills**: Network communication, data fusion, coordination, distributed processing

**Extensions**: Consensus algorithms, view planning, collaborative tracking

---

### 15. Drone Racing with Vision
**Description**: Use computer vision to autonomously race through course marked with gates.

**Key Skills**: Real-time detection, high-speed processing, predictive control, optimization

**Extensions**: Trajectory optimization, learning from demonstration, adaptive strategies

---

### 16. Wildlife Monitoring System
**Description**: Detect and track animals (toy or real), identify species, log behaviors and locations.

**Key Skills**: Object detection, classification, tracking, behavioral analysis

**Extensions**: Multiple species, behavior recognition, conservation metrics

---

## Research-Level Projects (10-15 weeks)

### 17. Learning-Based Visual Control
**Description**: Train neural network to control drone directly from camera images using reinforcement learning.

**Key Skills**: Deep RL, simulation, vision-based control, transfer learning

**Extensions**: Sim-to-real transfer, different tasks, generalization

---

### 18. Semantic Segmentation for Scene Understanding
**Description**: Classify every pixel in image (sky, ground, obstacles, targets) for advanced autonomy.

**Key Skills**: Semantic segmentation, scene understanding, real-time inference

**Extensions**: Instance segmentation, 3D semantic mapping, planning integration

---

### 19. Visual Teach & Repeat
**Description**: Manually fly route once while recording, then autonomously repeat using visual odometry.

**Key Skills**: Visual odometry, feature matching, loop closure, control

**Extensions**: Route optimization, adaptation to changes, multiple routes

---

### 20. Drone-Based Inspection System
**Description**: Autonomously inspect infrastructure (model bridges, towers), detect defects, generate reports.

**Key Skills**: Inspection planning, defect detection, 3D mapping, reporting

**Extensions**: Change detection, severity assessment, automated scheduling

---
