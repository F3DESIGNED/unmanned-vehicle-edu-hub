# Feature Detection and Tracking

**Duration**: 2-3 hours | **Difficulty**: Advanced | **Prerequisites**: OpenCV basics, object detection

## Lesson Overview (OUTLINE)

Learn to detect distinctive features in images and track them across video frames, enabling target following and visual odometry applications.

## Learning Objectives

1. Detect corners and features using Harris, FAST, ORB
2. Implement optical flow tracking (Lucas-Kanade)
3. Track objects using feature matching
4. Handle occlusion and tracking failures
5. Apply tracking to autonomous following missions

## Key Topics

- Feature detection algorithms (corners, blobs, edges)
- Feature descriptors (ORB, SIFT, SURF)
- Optical flow for motion tracking
- Multi-object tracking
- Kalman filtering for prediction

## Exercises

- Detect features in live video
- Track single feature across frames
- Multi-target tracking
- Target following mission
