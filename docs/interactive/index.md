# Interactive Content Framework

Hands-on digital learning experiences that support unmanned vehicle systems education.

## Overview

Interactive content provides students with safe, accessible ways to learn concepts and practice skills before working with physical hardware.

## Content Types

### Web-Based Simulators
Browser-based tools for learning concepts
- Flight dynamics
- PID tuning
- Sensor behavior
- Mission planning
- See: [Web-Based Simulators](simulators/web-based-simulators.md)

### Virtual Labs
Structured lab experiences using simulation tools
- [Arduino/Tinkercad Labs](virtual-labs/arduino-tinkercad-labs/) - 10 progressive labs
- [Drone Simulation Labs](virtual-labs/drone-simulation-labs/) - SITL and mission planning
- [ROS/Gazebo Labs](virtual-labs/ros-gazebo-labs/) - Advanced autonomy

### Self-Assessment Quizzes
Knowledge checks and skill assessments
- [Safety Quiz](self-assessment-quizzes/safety-quiz.md) (required before hardware)
- [Basic Electronics Quiz](self-assessment-quizzes/basic-electronics-quiz.md)
- Topic-specific quizzes
- See: [Quiz Template](self-assessment-quizzes/quiz-template.md)

### Interactive Troubleshooting
Flowcharts and decision trees for systematic problem-solving
- [Motor Not Spinning](interactive-troubleshooting/motor-not-spinning-flowchart.md)
- [Connection Problems](interactive-troubleshooting/)
- See: [Flowchart Template](interactive-troubleshooting/troubleshooting-flowchart-template.md)

## Using Interactive Content

### Benefits

**For Students:**
- Safe experimentation
- Immediate feedback
- Unlimited attempts
- Accessible from home
- No equipment costs
- Build confidence before hardware

**For Educators:**
- Differentiated learning
- Flipped classroom support
- Assessment tools
- Reduced equipment wear
- Extended learning time

### Integration Strategies

**Before Hardware:**
- Teach concepts in simulator
- Practice procedures virtually
- Build intuition safely
- Assess readiness

**Alongside Hardware:**
- Theory in simulator
- Practice on hardware
- Compare sim vs. real
- Troubleshoot safely

**When Hardware Unavailable:**
- Remote learning
- Weather/space constraints
- Equipment maintenance
- Budget limitations

**Assessment:**
- Pre-assessments (readiness)
- Formative checks (understanding)
- Skill demonstrations (competency)
- Self-assessment (metacognition)

## Contributing

**Submit your interactive content:**
1. Test thoroughly
2. Provide clear instructions
3. Include learning objectives
4. Document technical requirements
5. Submit via GitHub

## Technical Requirements

**Most content requires:**
- Modern web browser
- Internet connection
- No special software

**Some advanced content may need:**
- Specific software (provided free)
- Higher-end computer
- Installation instructions provided

## Accessibility

**All interactive content should:**
- Work with keyboard navigation
- Include alt text
- Provide text alternatives
- Support screen readers
- Use high-contrast colors

See: [Accessibility Guidelines](../accessibility/)
