# Ethics Discussion Rubric

## Participation & Engagement (25 points)

| Criteria | Developing (1-2) | Proficient (3) | Advanced (4-5) |
|----------|-----------------|---------------|--------------|
| **Frequency** | Rarely participates | Regular contributions | Frequent, timely contributions |
| **Quality** | Surface-level comments | Thoughtful comments | Insightful, nuanced contributions |
| **Listening** | Doesn't build on others | Sometimes builds on others | Consistently builds on and references others |

## Ethical Reasoning (50 points)

| Criteria | Developing (1-2) | Proficient (3) | Advanced (4-5) |
|----------|-----------------|---------------|--------------|
| **Framework Application** | Doesn't use frameworks | Applies one framework | Applies multiple frameworks effectively |
| **Stakeholder Analysis** | Limited perspective | Considers main stakeholders | Comprehensive stakeholder analysis |
| **Justification** | Weak or emotional reasoning | Logical reasoning | Strong, well-supported arguments |
| **Complexity** | Sees issues as simple | Recognizes some complexity | Embraces ambiguity and nuance |

## Critical Thinking (25 points)

| Criteria | Developing (1-2) | Proficient (3) | Advanced (4-5) |
|----------|-----------------|---------------|--------------|
| **Questions** | Accepts statements | Asks clarifying questions | Asks probing, thoughtful questions |
| **Analysis** | Superficial analysis | Adequate analysis | Deep, thorough analysis |
| **Synthesis** | No new insights | Some synthesis | Creative synthesis and solutions |

## Total: 100 points

## Written Reflection Component (if applicable)

- [ ] Clearly states position
- [ ] Provides evidence and reasoning
- [ ] Considers counterarguments
- [ ] Demonstrates growth in thinking
- [ ] Well-organized and clear
