# Getting Started with Unmanned Vehicle Systems

Welcome to the Getting Started section! This is your entry point into the world of unmanned aerial and ground vehicles in education.

## Purpose

This section provides foundational knowledge for educators, students, and technical staff who are new to unmanned vehicle systems. Whether you're setting up your first classroom drone program or exploring robotics for the first time, start here.

## What You'll Find Here

- **Safety Fundamentals** - Critical safety protocols and regulations overview
- **Basic Concepts** - Essential terminology and principles
- **Equipment Selection** - Guidance on choosing platforms and components
- **First Builds** - Simple starter projects to build confidence
- **Classroom Setup** - Recommendations for educational environments
- **Budget Planning** - Cost-effective approaches for schools

## How to Navigate

1. **Complete beginners** - Read in order from safety-first.md through classroom-setup.md
2. **Experienced educators** - Jump to classroom-setup.md for educational-specific guidance
3. **Students** - Focus on basic-concepts.md and first-build guides
4. **Technical staff** - Review safety-first.md and equipment-guide.md

## Prerequisites

- None! This section is designed for absolute beginners
- Recommended: Basic understanding of electronics (helpful but not required)
- Recommended: Familiarity with your local aviation regulations

## Estimated Time

- **Reading all content**: 3-5 hours
- **First build project**: 4-8 hours
- **Classroom setup**: 2-4 hours planning

## Safety Notice

**⚠️ IMPORTANT:** Before proceeding with any hands-on activities, read the [Safety & Compliance](../safety-compliance/) documentation thoroughly. Operating unmanned systems involves real risks that must be properly managed in educational settings.
