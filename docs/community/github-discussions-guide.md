# GitHub Discussions Guide

GitHub Discussions is our primary platform for community conversation, support, and collaboration.

## Accessing Discussions

**Direct link:** [https://github.com/F3DESIGNED/unmanned-vehicle-edu-hub/discussions](https://github.com/F3DESIGNED/unmanned-vehicle-edu-hub/discussions)

**Requirements:**
- Free GitHub account
- Accept community guidelines

## Discussion Categories

### 📢 Announcements & Updates
**Purpose:** Official community announcements
**Who posts:** Community moderators and coordinators
**Who can read:** Everyone
**Examples:** New resources, events, program updates, community milestones

### ❓ Q&A - Technical Support (Hardware)
**Purpose:** Hardware troubleshooting and building questions
**Best for:** Motors, ESCs, frames, wiring, sensors, batteries, assembly
**How it works:** Ask question → Community answers → Mark best answer
**Response time:** Usually < 24 hours

### 💻 Q&A - Technical Support (Software)
**Purpose:** Software, firmware, and programming questions
**Best for:** BetaFlight, ArduPilot, PX4, coding, mission planning, configuration
**How it works:** Same as hardware Q&A
**Response time:** Usually < 24 hours

### 🎓 Q&A - Teaching & Pedagogy
**Purpose:** Teaching strategies and classroom questions
**Best for:** Lesson planning, classroom management, assessment, differentiation, engagement
**How it works:** Ask question → Share experiences and strategies
**Response time:** Usually < 48 hours

### 🏆 Show & Tell - Student Projects
**Purpose:** Showcase student work and achievements
**Post:** Photos, videos, descriptions of student projects
**Why:** Celebrate students, inspire others, build community
**Guidelines:** Get permission before posting, no last names

### ✨ Show & Tell - Educator Implementations
**Purpose:** Share your program, curriculum, innovations
**Post:** How you're implementing, what's working, lessons learned
**Why:** Learn from each other, celebrate success, inspire adoption

### 💡 Ideas & Feature Requests
**Purpose:** Suggest improvements to resources or community
**Post:** New resource ideas, website features, community programs
**How it works:** Propose → Discuss → Community votes → Prioritize
**Examples:** New lesson topics, tool requests, event ideas

### 📚 Lesson Plan Exchange
**Purpose:** Share and request lesson plans
**Post:** Complete lessons, activities, units, or requests for specific topics
**Format:** Use lesson plan template when sharing
**Why:** Save time, improve quality, adapt proven lessons

### 🔧 Troubleshooting Workshop
**Purpose:** Collaborative problem-solving for complex issues
**Best for:** Problems that need multiple perspectives or extended discussion
**Different from Q&A:** Longer discussions, multiple possible solutions, learning process

### 🌍 Regional Chapters
**Purpose:** Organize and discuss local chapter activities
**Post:** Meeting announcements, local resources, regional events
**Who:** Chapter members and those interested in starting chapters

### 🤝 Collaboration & Partnerships
**Purpose:** Find collaborators, partners, or team members
**Post:** Project proposals, grant collaborations, research partnerships, joint initiatives
**Examples:** Co-developing curriculum, multi-school projects, research studies

### 💰 Grants & Funding Opportunities
**Purpose:** Share and discuss funding opportunities
**Post:** Grant announcements, application tips, success stories, collaboration offers
**Why:** Many grants stronger with partnerships; shared knowledge improves success

### 🎯 Competition Teams
**Purpose:** Support for competition preparation
**Post:** Strategy discussions, rule clarifications, team management, technical challenges
**Competitions:** FIRST, VEX, drone racing, autonomous challenges, etc.

## How to Use Discussions Effectively

### Asking Good Questions

**Include:**
1. **Clear title** - Descriptive, specific
2. **Context** - Your situation, experience level, goals
3. **What you've tried** - Shows effort, helps avoid repeat suggestions
4. **Specific details** - Error messages, configurations, photos
5. **What success looks like** - What outcome you want

**Example good question:**
```
Title: "Motor 3 stuttering on BetaFlight F4 - tried ESC calibration"

I'm setting up my first quadcopter build for my high school class. Motor 3
stutters in the motor test while others spin smoothly.

Setup:
- BetaFlight 4.3
- F4 flight controller
- 30A 4-in-1 ESC (BlHeli_S)
- 2205 2300KV motors

Tried:
- ESC calibration (no change)
- Swapped motor to different port (problem follows the ESC output)
- Checked all connections (seem secure)
- Updated firmware

The motor works fine when connected directly to battery.

What should I check next? Could this be an ESC issue?

[Photos attached]
```

### Answering Questions

**Be helpful:**
- Read carefully before responding
- Ask clarifying questions if needed
- Explain your reasoning
- Link to resources
- Be patient and kind
- Follow up if asked

**Avoid:**
- "Just Google it" responses
- Assumptions about knowledge level
- Dismissing "basic" questions
- Speculation without disclosure

### Sharing Projects

**Include:**
- Clear photos or videos
- Description of project
- Grade level and context
- What students learned
- Challenges faced
- Resources used
- Permission to post student work

### Making Feature Requests

**Good format:**
1. **What:** Clear description of request
2. **Why:** Problem it solves or value it adds
3. **Who:** Who would benefit
4. **Examples:** Similar things that exist elsewhere
5. **Willing to help:** Can you contribute to development?

## Discussion Etiquette

### Do:
✅ Search before posting (might already be answered)
✅ Use appropriate category
✅ Be respectful and constructive
✅ Mark helpful answers
✅ Update if you solve your own problem
✅ Thank people who help
✅ Help others when you can

### Don't:
❌ Cross-post same question in multiple categories
❌ Bump your post repeatedly
❌ Demand immediate responses
❌ Attack or insult
❌ Share others' personal information
❌ Advertise products excessively

## Moderation

**Community moderated by volunteers**

**Report issues:**
- Use GitHub's report function
- Tag @moderators
- Email: moderators@[placeholder]

**Moderation actions:**
- Gentle reminders
- Moving posts to correct category
- Editing for clarity or safety
- Warning for violations
- Temporary restrictions
- Permanent bans (severe/repeated violations)

## Notifications

**Manage your notifications:**
- Watch categories you're interested in
- Unwatch threads that are resolved
- Set notification frequency in GitHub settings
- Use filters to manage volume

## Tips for Success

**Get the most from discussions:**
1. **Introduce yourself** in Announcements
2. **Watch** categories relevant to you
3. **Answer** questions where you have expertise
4. **Share** your successes and lessons
5. **Ask** without fear - all questions valid
6. **Upvote** helpful posts
7. **Mark** best answers
8. **Be patient** - volunteers respond when able
9. **Give back** - help others as you're helped
10. **Build relationships** - this is community!

## Privacy

**Public vs. Private:**
- All discussions are PUBLIC
- Anyone can read (even without account)
- Don't share sensitive information
- Student privacy: no names/faces without permission
- Personal info: share carefully

## Search Tips

**Find what you need:**
- Use GitHub's search bar
- Filter by category
- Sort by activity or date
- Search specific user's posts
- Use labels and tags

**Search operators:**
- `"exact phrase"` - Exact match
- `author:username` - Posts by user
- `label:labelname` - Posts with label
- `is:answered` - Answered questions
