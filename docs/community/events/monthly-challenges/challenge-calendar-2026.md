# Monthly Challenge Calendar 2026

## January: Safety First Challenge
**Build a safety training module**

**Objective:** Create comprehensive safety training for your students
**Levels:**
- 🥉 Bronze: Adapt existing safety materials for your context
- 🥈 Silver: Create original safety quiz and assessment
- 🥇 Gold: Develop complete safety certification program

**Why:** Safety must come first. Start the year right.

---

## February: First Flight Challenge
**Get something airborne safely**

**Objective:** Successfully configure and fly a multirotor (sim or real)
**Levels:**
- 🥉 Bronze: Complete stable hover in simulator
- 🥈 Silver: Successful flight in controlled environment
- 🥇 Gold: Develop student-friendly first flight curriculum

**Why:** Nothing beats the excitement of first flight!

---

## March: Code Your Quad Challenge
**Program autonomous behavior**

**Objective:** Write code to control autonomous flight
**Levels:**
- 🥉 Bronze: Simple waypoint navigation
- 🥈 Silver: Sensor-triggered behavior
- 🥇 Gold: Complete autonomous mission with student lesson plan

**Why:** Programming brings autonomy to life.

---

## April: Sensor Fusion Challenge
**Integrate multiple sensors**

**Objective:** Combine data from multiple sensors for enhanced capability
**Levels:**
- 🥉 Bronze: Read and display data from 2 different sensors
- 🥈 Silver: Use sensor data to trigger actions
- 🥇 Gold: Implement Kalman filter or sensor fusion algorithm

**Why:** Understanding sensor integration is key to autonomy.

---

## May: Mission Possible Challenge
**Plan and execute complex mission**

**Objective:** Create and execute multi-stage autonomous mission
**Levels:**
- 🥉 Bronze: 3-waypoint mission with takeoff and landing
- 🥈 Silver: Mission with conditional actions and error handling
- 🥇 Gold: Competition-style mission with student documentation

**Why:** Missions demonstrate practical applications.

---

## June: Project-Based Learning Challenge
**Design student project**

**Levels:**
- 🥉 Bronze: Define project scope and learning objectives
- 🥈 Silver: Complete project plan with rubric
- 🥇 Gold: Pilot project with students and document results
