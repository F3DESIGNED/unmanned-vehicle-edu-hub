# Monthly Challenge Format

Monthly challenges are hands-on activities designed to build skills, encourage experimentation, and foster community engagement.

## Challenge Structure

### Each Challenge Includes:

**1. Clear Objective**
- What you'll build/learn/accomplish
- Why it matters for teaching
- Expected time commitment

**2. Success Criteria**
- How to know you've completed it
- Multiple levels (bronze, silver, gold)
- Room for creativity and extension

**3. Resources**
- Required materials
- Tutorials and guides
- Example solutions
- Troubleshooting help

**4. Community Component**
- Discussion thread
- Share your results
- Help others
- Collective learning

**5. Reflection Prompts**
- What did you learn?
- How will you use this with students?
- What challenges did you face?
- What would you do differently?

## Challenge Levels

### Bronze 🥉
Basic completion meeting minimum requirements
- Great for beginners
- Follows provided guidance
- Achieves core objective

### Silver 🥈
Enhanced version with additional features
- Adds personal touches
- Explores variations
- Documents process

### Gold 🥇
Advanced implementation with innovation
- Significant customization
- Teaching application developed
- Shareable resource created
- Helps others succeed

## Challenge Types

### Technical Challenges
- Build specific hardware
- Configure systems
- Program behaviors
- Troubleshoot scenarios

### Pedagogical Challenges
- Develop lesson plans
- Create assessments
- Try new teaching strategies
- Gather student feedback

### Creative Challenges
- Design custom solutions
- Innovate on existing designs
- Combine multiple concepts
- Solve authentic problems

### Community Challenges
- Help others
- Create resources
- Lead sessions
- Build connections

## Participating in Challenges

**1. Join the Challenge**
- Read challenge description
- Gather materials
- Join Discussion thread
- Set your level goal

**2. Work on Challenge**
- Follow guidelines
- Experiment and explore
- Document as you go
- Ask for help when stuck

**3. Share Your Work**
- Post in Discussion thread
- Share photos/videos
- Describe your process
- Celebrate your achievement

**4. Help Others**
- Answer questions
- Share tips
- Encourage participants
- Build community

**5. Reflect**
- Complete reflection prompts
- Consider teaching applications
- Identify learning
- Set next goals

## Creating Your Own Challenge

Want to propose a challenge?
1. Use [Challenge Template](challenges/challenge-template.md)
2. Submit to community coordinators
3. Community votes on upcoming challenges
4. Top challenges scheduled

**Great challenges:**
- Build specific skills
- Are achievable in reasonable time
- Have clear success criteria
- Encourage creativity
- Support diverse skill levels
- Apply to teaching practice
