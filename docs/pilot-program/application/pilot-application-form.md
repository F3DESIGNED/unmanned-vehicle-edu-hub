# Unmanned Vehicle Systems Education Hub - Pilot Program Application

## Application Instructions

Thank you for your interest in becoming a pilot school for the Unmanned Vehicle Systems Education Hub! This application will help us understand your school's context, goals, and readiness to implement our curriculum.

**Application Deadline:** Applications are reviewed on a rolling basis. Priority consideration for Cohort 1 (Spring 2026) given to applications received by October 15, 2025.

**Selection Timeline:**
- Applications reviewed within 2 weeks of submission
- Finalist interviews conducted within 4 weeks
- Final selections announced 6 weeks before cohort start date

**Questions?** Contact pilot-program@uvs-edu-hub.org
