# Pilot Program - UVS Education Hub

## Welcome to the Pilot Program

The UVS Education Hub Pilot Program partners with schools to implement, test, and refine our unmanned vehicle systems curriculum. Pilot schools receive comprehensive support, contribute to program evaluation, and help shape the future of UVS education.

---

## Purpose

The pilot program serves to:
- **Test** curriculum effectiveness across diverse school contexts
- **Gather feedback** from teachers and students to improve materials
- **Document** implementation practices and outcomes
- **Build evidence** of program impact
- **Develop** sustainable models for scaling
- **Create community** of practice among educators

---

## Program Structure

### Cohorts
Schools participate in defined cohorts that:
- Start together with coordinated professional development
- Form learning communities for peer support
- Contribute to research and evaluation
- Share lessons learned
