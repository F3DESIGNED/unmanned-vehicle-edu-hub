3. **Document implementation** through case studies and research

6. **Develop sustainability** models for program continuation

## Data Collection and Evaluation

### Required Data Collection

**Pre-Implementation:**
- School profile
- Teacher background survey
- Student pre-assessments (knowledge, skills, attitudes)

**During Implementation:**
- Weekly teacher reflection logs
- Monthly implementation surveys
- Student attendance and engagement data
- Photos/videos (with releases)
- Classroom observations (2 per school)

**Post-Implementation:**
- Student post-assessments (knowledge, skills, attitudes)
- Student feedback surveys
- Teacher end-of-semester survey
- Administrator survey
- Final interviews

- **January 2026:** Pre-assessments administered

- Increased knowledge of unmanned systems and related technologies
- Development of technical skills (flight, programming, engineering)
- Enhanced problem-solving and critical thinking
- Increased interest in STEM fields and careers

- Increased technical content knowledge
- Enhanced pedagogical skills in hands-on, project-based learning

- Professional network and community of practice

- Increased student engagement in technical programs

- Model for introducing innovative curriculum

**Program-Level:**

- Identified best practices and challenges
- Refined support systems
- Evidence base for scaling
