# Cohort Template

## Instructions for Creating New Cohort Folder

When setting up a new pilot cohort, copy this template folder and customize it for your cohort.

---

## Steps to Create New Cohort

1. **Copy this folder** and rename it with cohort identifier
   - Format: `cohort-[number]-[season]-[year]`
   - Example: `cohort-2-fall-2026`

2. **Create subfolders:**
   ```
   cohort-X-season-year/
   ├── README.md
   ├── school-profiles/
   ├── weekly-updates/
   └── outcomes/
   ```

3. **Customize README.md:**
   - Update cohort name and dates
   - Add participating schools
   - Customize timeline and milestones
   - Update contact information
   - Add cohort-specific goals or focus areas

4. **Set up school-profiles folder:**
   - Create one profile document per school
   - Use naming: `[school-name]-profile.md`
   - Track implementation progress and context

5. **Set up weekly-updates folder:**
   - Aggregate weekly reflections (anonymized)
   - Share common themes with cohort
   - Track cohort-wide progress

6. **Set up outcomes folder:**
   - Store cohort-level data summaries
   - Case studies for cohort schools
   - Final cohort report

## Outcomes Folder Structure

In the `outcomes/` folder, organize:

```
outcomes/
├── data-summaries/
│   ├── pre-assessment-summary.md
│   ├── mid-semester-summary.md
│   └── post-assessment-summary.md
├── case-studies/
│   ├── school-1-case-study.md
│   ├── school-2-case-study.md
│   └── school-3-case-study.md
├── success-stories/
│   ├── story-1.md
│   └── story-2.md
└── final-report/
    └── cohort-[X]-final-report.md
```

## Customization Checklist

When setting up a new cohort, ensure you:

☐ Copy and rename folder
☐ Create all subfolders (school-profiles, weekly-updates, outcomes)
☐ Customize README with cohort details
☐ Update dates and timeline
☐ Add participating school information
☐ Update contact information
☐ Create school profile documents
☐ Set up data collection templates
☐ Establish communication channels
☐ Link to cohort-specific resources

## Notes

- Keep school profiles updated throughout implementation
- Post weekly updates to keep cohort informed
- Document successes and challenges in real-time
- Compile outcomes data progressively
- Maintain confidentiality for sensitive information
