## Common Issues: Quick Reference

**Before submitting form, try these quick fixes:**

### Drone won't turn on
1. Check battery is charged and properly inserted
2. Hold power button for 3-5 seconds
3. Try different battery
4. Check for physical damage

### Drone won't connect to controller
1. Turn on controller first, then drone
2. Ensure controller is charged
3. Check Bluetooth/WiFi is enabled on device
4. Try pairing process from scratch (consult manual)
5. Move away from WiFi routers (interference)

### Drone flies erratically
1. Recalibrate compass (follow app instructions)
2. Recalibrate IMU
3. Fly in open area away from metal/magnetic interference
4. Check propellers installed correctly and not damaged
5. Ensure weather conditions appropriate (not too windy)

### App won't connect to drone
1. Close and reopen app
2. Ensure WiFi/Bluetooth enabled
3. Turn drone off and on
4. Restart device (phone/tablet)
5. Update app to latest version
6. Check permissions (camera, location if needed)

### Cannot access online curriculum
1. Check internet connection
2. Clear browser cache and cookies
3. Try different browser
4. Reset password
5. Contact tech-support@uvs-edu-hub.org
