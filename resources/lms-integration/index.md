# LMS Integration Packages

Platform-specific guides for integrating drone curriculum into Learning Management Systems.

## Supported Platforms

### [Canvas](./canvas/)
Popular in higher education and growing in K-12

### [Google Classroom](./google-classroom/)
Widely used in K-12, free for schools

### [Schoology](./schoology/)
K-12 focused LMS

### [Moodle](./moodle/)
Open-source, highly customizable

## What's Included

Each platform package includes:
- Setup guide
- Course structure template
- Module/topic organization
- Assignment templates
- Grading rubrics
- Student resources organization

## Benefits of LMS Integration

- **Organization**: All materials in one place
- **Accessibility**: Students access anytime
- **Tracking**: Monitor progress and completion
- **Communication**: Announcements and messaging
- **Assessment**: Built-in grading tools
- **Parent Access**: Transparency for families
