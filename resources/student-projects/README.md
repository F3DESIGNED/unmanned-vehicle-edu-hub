# Student Projects

Project templates and exemplars for student-led unmanned vehicle projects.

## Purpose

Scaffolded project templates and example projects that students can complete independently or in groups.

## Project Types

### Beginner Projects
- Pre-planned with detailed instructions
- Limited customization options
- 2-4 hours completion time

### Intermediate Projects
- More design choices
- Problem-solving required
- 8-12 hours completion time

### Advanced Projects
- Open-ended challenges
- Student-driven design
- 20+ hours completion time

## What's Included

Each project includes:
- Project brief/challenge
- Learning objectives
- Required materials
- Safety requirements
- Design constraints
- Assessment rubric
- Extension ideas

## Project Categories

- First builds
- Racing challenges
- Autonomous missions
- Payload delivery
- Search and rescue scenarios
- Custom designs
