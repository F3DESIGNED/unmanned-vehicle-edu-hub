# Lesson Plans

Individual lesson plans for unmanned vehicle education.

## Purpose

Ready-to-teach individual lessons (45-90 minutes) that can be used standalone or combined into custom units.

## Lesson Plan Format

Each lesson includes:
- Learning objectives
- Standards alignment
- Materials list
- Safety considerations
- Instructional sequence
- Assessment methods
- Differentiation strategies

## Organization

### By Topic
- UAV basics and concepts
- UGV robotics
- Programming and automation
- Safety and regulations
- Engineering design

### By Grade Level
- Elementary (K-5)
- Middle School (6-8)
- High School (9-12)

### By Duration
- 45-minute lessons
- 90-minute lessons
- Full project days
