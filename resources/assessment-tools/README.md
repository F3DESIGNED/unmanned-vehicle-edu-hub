# Assessment Tools

Rubrics, checklists, and evaluation tools for unmanned vehicle education.

## Purpose

Ready-to-use assessment instruments for evaluating student learning across knowledge, skills, and project work.

## Assessment Types

### Formative Assessments

- Entry/exit tickets
- Observation checklists
- Quick checks for understanding
- Self-assessment tools

### Summative Assessments

- Project rubrics
- Performance assessments
- Written reflections
- Presentations

### Skill-Based Assessments

- Build quality checklists
- Flight skill evaluations
- Programming proficiency
- Safety protocol adherence

## Rubric Categories

### Technical Skills
- Assembly and wiring
- Flight control
- Programming
- Troubleshooting

### Design Process
- Problem identification
- Research and planning
- Prototyping
- Testing and iteration

### Collaboration
- Teamwork
- Communication
- Task management
- Peer support

### Documentation
- Technical writing
- CAD drawings
- Code comments
- Project logs
