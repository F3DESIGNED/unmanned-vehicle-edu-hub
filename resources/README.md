# Educational Resources

Complete educational materials for K-12 unmanned vehicle systems programs.

## Purpose

This directory contains complete curriculum packages, individual lesson plans, student project templates, and assessment tools for educators.

## Directory Structure

```
resources/
├── README.md (this file)
├── curriculum/               # Complete multi-week units
├── lesson-plans/             # Individual lesson plans
├── student-projects/         # Project templates and examples
└── assessment-tools/         # Rubrics and evaluation tools
```

## What You'll Find

### Curriculum Packages
- Multi-week instructional units
- Complete with assessments
- Standards-aligned (NGSS, Common Core, ISTE, CTE)
- Differentiation strategies included

### Lesson Plans
- Individual 45-90 minute lessons
- Ready to use
- Multiple grade levels
- Various topics and skills

### Student Projects
- Project templates
- Exemplar projects
- Assessment rubrics
- Skill progressions

### Assessment Tools
- Formative assessments
- Summative rubrics
- Self-assessments
- Peer evaluation forms
