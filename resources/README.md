# Resources

This folder contains curriculum materials, assessment tools, and professional development resources.

## Contents

- **curriculum/**: Course outlines, unit plans, pacing guides
- **student-projects/**: Project templates, examples, showcase submissions
- **assessment-tools/**: Tests, rubrics, checklists, certification exams
- **professional-development/**: Teacher training materials, workshop outlines

## Usage

These materials are ready-to-use in educational settings. All files are provided under the CC-BY-SA 4.0 license unless otherwise noted.
