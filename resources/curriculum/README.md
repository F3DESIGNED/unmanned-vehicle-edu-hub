# Curriculum Packages

Complete multi-week instructional units for unmanned vehicle systems.

## Purpose

Standards-aligned curriculum units with lesson plans, assessments, and all supporting materials for multi-week instruction.

## Structure

Each curriculum package includes:
- Unit overview and objectives
- Standards alignment document
- Complete lesson plans (typically 4-8 lessons)
- Student handouts and worksheets
- Assessment tools and rubrics
- Teacher guide and notes
- Required materials list

## Available Units

### By Grade Level

**Elementary (K-5)**
- Introduction to Drones (4 lessons)

**Middle School (6-8)**
- Build and Fly a Quadcopter (6 lessons)
- Arduino Rover Challenge (8 lessons)

**High School (9-12)**
- Autonomous Navigation Systems (6 weeks)
- Drone Racing and FPV Flight (4 weeks)
