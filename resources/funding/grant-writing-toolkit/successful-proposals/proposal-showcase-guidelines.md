# Proposal Showcase Guidelines

This directory will contain anonymized examples of successful grant proposals.

## Contributing Proposals

If you've written a successful grant proposal and are willing to share (with identifying information removed):

1. Anonymize all identifying information
2. Get permission from funding organization
3. Include award amount and funder type
4. Note what made it successful

## Using These Examples

- Learn structure and style
- See how to present data
- Understand budget justification
- Don't copy directly (adapt to your situation)
