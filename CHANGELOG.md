# Changelog

All notable changes to the Unmanned Vehicle Systems Education Hub will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-XX

### Added - Phase 3: Support Resources

#### Control Systems Documentation
- Complete control systems overview with learning progression
- Manual control guide (RC basics, flight modes, emergency procedures)
- FPV systems comprehensive guide (cameras, VTx, goggles, setup)
- Autonomous control documentation (waypoint nav, sensor autonomy)
- MAVLink protocol guide (telemetry, commands, companion computers)
- Advanced control techniques (PID tuning, state estimation, path planning)

#### Troubleshooting Documentation
- Comprehensive troubleshooting index with diagnostic framework
- Diagnostic flowcharts (7 Mermaid decision trees for common issues)
- Hardware issues guide (categorized by symptom with solutions)
- Software issues troubleshooting (firmware, configuration, parameters)
- Flight operation issues (stability, GPS, unexpected behavior)
- Log analysis guide (ArduPilot and Betaflight)
- Safety incident response procedures
- Preventive maintenance schedules and checklists

#### Curriculum Integration
- Curriculum integration overview
- Standards alignment (NGSS, Common Core Math, ISTE Standards)
- CTE pathway integration
- Complete lesson plan: Forces in Flight (Physics, 9-12)
- Additional lesson plans (navigation, algorithms, aerodynamics, design, GPS)
- Project-based units (search & rescue, autonomous delivery)
- Competition preparation guide
- Assessment rubrics

#### References Documentation
- References index and overview
- Technical references (datasheets, protocols, performance databases)
- Educational resources (textbooks, online resources, tutorials)
- Community resources (forums, organizations, social media)
- Vendor and supplier directory
- Software tools directory

#### Expanded Glossary
- Expanded from 50 to 150+ terms
- Category pages (aeronautical, electronic, programming, protocols, regulatory)
- Visual aids for key components
- Cross-referenced terms

#### Resources Folder
- Curriculum resources (semester outline, quarter plan)
- Student project templates and examples
- Assessment tools (safety certification, skills checklist, rubrics)
- Professional development materials

#### Media Organization
- Organized media folder structure
- Placeholder directories for images (diagrams, components, builds)
- Attribution documentation

#### GitHub Pages & CI/CD
- Automated deployment workflow
- Link checking workflow
- Markdown linting workflow
- Build validation on pull requests

#### Documentation
- Comprehensive CHANGELOG
- ROADMAP for future development
- Enhanced README with badges and quick reference
- Contributing guidelines

### Changed
- Updated mkdocs.yml with complete navigation for all new content
- Enhanced site configuration for better user experience
- Improved cross-referencing between sections
