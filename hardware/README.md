# Hardware Designs

Open-source hardware designs for UAV and UGV systems.

## Purpose

This directory contains CAD files, bills of materials (BOMs), assembly guides, and specifications for building unmanned vehicles.

## Directory Structure

```
hardware/
├── README.md (this file)
├── uav-designs/              # Aerial vehicle designs
├── ugv-designs/              # Ground vehicle designs
├── bill-of-materials/        # Component lists with sourcing
└── assembly-guides/          # Build instructions
```

## What You'll Find

### UAV Designs
- Quadcopter frames (250mm to 450mm)
- Fixed-wing airframes
- Racing drone frames
- Educational platforms

### UGV Designs
- Arduino rover chassis
- Raspberry Pi vehicles
- Competition robots
- Modular platforms

### Bills of Materials
- Complete component lists
- Supplier links
- Cost estimates
- Alternative options

### Assembly Guides
- Step-by-step instructions
- Photo documentation
- Tool requirements
- Time estimates

## File Formats

- **CAD**: STEP, STL, Fusion 360, SolidWorks
- **Drawings**: PDF, DXF
- **BOM**: Markdown tables, CSV
- **Assembly**: Markdown with images

## Design Philosophy

All designs prioritize:
- **Educational value** - Learning through building
- **Safety** - Appropriate for school environments
- **Cost-effectiveness** - Budget-friendly options
- **Modularity** - Adaptable to different needs
- **Open source** - Free to use and modify
