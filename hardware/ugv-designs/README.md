# UGV Designs

Ground vehicle chassis and platform designs.

## Purpose

CAD files and specifications for Arduino rovers, Raspberry Pi vehicles, and educational ground robots.

## Design Categories

### Arduino Rovers
- Basic 2WD platforms
- 4WD all-terrain
- Tank-track designs

### Raspberry Pi Vehicles
- Advanced computing platforms
- Camera-equipped rovers
- Autonomous vehicles

### Competition Robots
- BattleBots-style designs
- Maze solvers
- Line followers
