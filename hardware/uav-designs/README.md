# UAV Designs

Airframe designs for unmanned aerial vehicles.

## Purpose

CAD files and specifications for quadcopters, fixed-wing aircraft, and other aerial platforms suitable for educational use.

## Design Categories

### Quadcopters
- **Micro** (< 250mm) - Indoor, beginner-friendly
- **Mini** (250-350mm) - Racing, learning
- **Standard** (350-450mm) - General purpose, stable
- **Large** (> 450mm) - Payload capacity, advanced

### Fixed-Wing
- Trainer aircraft
- Long-endurance platforms
- FPV wings

### Specialty
- VTOLs
- Hexacopters
- Custom platforms
