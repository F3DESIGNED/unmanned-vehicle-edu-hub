# Bill of Materials

Component lists with sourcing information for all hardware designs.

## Purpose

Complete BOMs with part numbers, suppliers, prices, and alternatives for building unmanned vehicles.

## BOM Format

Each BOM includes:
- Quantity needed
- Part description
- Specifications
- Approximate cost
- Supplier links
- Alternative options

## Budget Categories

- **Under $100** - Entry-level builds
- **$100-$300** - Standard educational builds
- **$300-$500** - Advanced systems
- **$500+** - Competition/research platforms
